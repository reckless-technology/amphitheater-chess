Reckless Amphitheater is a chess GUI and engine host for Windows, macOS and Linux: play against UCI engines, analyse a
position with several at once, and run matches and tournaments between them with clocks, opening books, pondering,
adjudication and PGN. amphitheater-cli runs the same matches and tournaments from the command line. The installers carry
five chess engines, ready to play the moment the host first opens: Pawnstar, Zenith, Pawnstar-Go, Pawnstar-RS and
Stoopid Chess, each a separate program under the GNU General Public License version 3, with its source a click away
in THIRD-PARTY-NOTICES.txt.

## What's changed

- Five chess engines come with the host and appear in the engine list on its first start, set to one thread and a
  64 MB hash; a new release moves them on and keeps your own settings, and one you remove stays removed.
- Installers for Windows (signed), macOS (signed and notarised) and Linux (a Debian package and a portable zip).
- On macOS the bundled engines are built for Apple silicon.
- The host has an icon of its own, the black queen on a white square, in the app, its installers and the menus.
- View offers window sizes of 50% to 150% (Ctrl+0, Ctrl+= and Ctrl+-, Command on a Mac), and the next launch opens at
  the size chosen.
